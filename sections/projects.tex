\cvsection{Open-Source Software}
\leftright{\textbf{LLM-for-Zotero}: AI research agent rooted in a Zotero library (\link{https://github.com/yilewang/llm-for-zotero}{GitHub})}{\textit{TypeScript, 2026 -- present}}
\begin{itemize}
  \item Sole architect and lead maintainer: \textbf{1,600+ commits, 117 releases, 19 contributors}; \textbf{3,000+ stars and 630K+ downloads}; supports Zotero 7--9 in English and Chinese.
  \item \textbf{Agent design:} bounded tool-use runtime with \textbf{38 tools} (library search and edits, PDF and figure reading, web search, scripting), a plan/amend coordinator, and a durable research graph that runs 50-paper literature reviews with screening, relevance rubrics, reading budgets, and verification.
  \item \textbf{Context engineering:} transcript compaction, a source-coverage ledger, an evidence cache, and prompt budgeting keep long multi-paper sessions inside the context window; per-turn model-call, tool-call, and cache-hit baselines are pinned as regression tests.
  \item \textbf{Safe autonomy:} centralized authorization with safe/auto/yolo modes, a change journal with undo and revert, and every library write verified against Zotero's native post-state.
  \item \textbf{Model-agnostic runtime:} 7 provider protocols (OpenAI-compatible, Anthropic, Gemini, Ollama, Codex) plus Claude Code and Codex app-server integrations through a built-in MCP server.
  \resumeonly{\item \textbf{Quality:} \textbf{6,600+ unit tests}, 90 workflow suites against a real Zotero instance, live-LLM evaluation suites, and CI with architecture-boundary and import-cycle checks.}
\end{itemize}
